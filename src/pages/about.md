# 关于我们

## 简介

我们 （ 即 RedStarMC社区 / RedStarMCCommunity / 红星我的世界社区 ） 目前正依托 Minecraft 服务器，开展核心社区运营工作。  
但我们的发展愿景不止于此，我们不仅希望能为玩家提供优质的生存游戏体验，还计划拓展多元化游戏玩法，包括各类小游戏、模组生存、创造服务器等。  
同时，我们希望能组建由玩家组成的建筑玩家社区、开发玩家社区、动画制作玩家社区等各类玩家玩家社区，为各位玩家提供一个快乐游玩、共同创造的平台。

目前，社区已搭建维基和 Github 组织，为社区发展与玩家互动提供坚实支撑。未来，我们计划进一步开发用户系统，以支持外置登录等相关功能，持续完善社区服务体系。

我们郑重承诺，社区将始终保持公益性质，不在游戏内设置任何收费项目及氪金内容，保障每一位玩家的公平游戏权益。

我们致力于打造一个和谐友爱的社区环境，坚决杜绝各类不良行为，包括但不限于发表低俗言论、传播不良图片、制作不雅建筑及网络暴力等，共同守护健康、积极的社区氛围。

我们目前致力于为 Minecraft:Java Edition 多人游戏服务器的创作，通常称为 “红星服务器”。

:::

## 组织架构

### 组成部分

社区由以下部分组成：

* 管理组
* Minecraft 服务器
* 官网
* 维基
* 社区所管辖的 QQ 群/频道
* RedStarMC Github 组织
* 外置登陆身份系统 （未开发完毕，未投入使用）

:::note 社区所有权

社区归全体玩家所有，社区利益即为全体玩家利益。社区由管理组领导，管理组实行民主集中制。

`管理组` 是社区的管理机构，管理其他各部分，对社区和玩家负责，受玩家监督，保证社区正常运转。管理组以全体玩家利益为自己的利益。

:::

### 玩家

所有正式加入社区且未被封禁的成员均为玩家，担任社区职务或加入管理组的前提是一名玩家。

### 社区职务

社区职务包括以下职务：

* `腐竹` 社区的主要管理者，负责统筹社区全面工作。
* `运行维护`（简称 `运维` ） 社区的主要管理者，主要负责运营，社区维护，保障社区各项服务正常运转。
* `管理` 社区的主要管理者，协助 `腐竹` 和 `运维` ，主要负责社区管理和运营。
* `协管` 主要负责社区管理，协助 `腐竹` 和 `运维`。
* `建筑师` 主要负责社区内 Minecraft 服务器的建筑等内容创作。
* `核心玩家` 社区的主要监督者，监督其他职务，和玩家深入交流，确保管理组能准确执行全体玩家的意愿。
* `开发 / 技术人员` 社区负责其他方面的人员，单独列出。

除 `腐竹` 和 `运行维护` 外，其他职位正式担任前均可设置一段实习期。实习期的长度、是否实行、是否转正由管理组决定。实习期职务在原职务名前加 `实习` 或 `见习` 。  
`协管`、`建筑师`、`开发 / 技术人员` 直接由社区玩家自行申请担任。

### 管理组 {#Management-Committee}

管理组由以下人员组成：

* 组长
* 副组长若干人
* 组员若干人

管理组实行集体领导、民主集中、个别酝酿、会议决定。  
管理组的职权包括：任免 `腐竹`、`运行维护`、`管理`，制定社区规则，决定是否封禁玩家，决定其他社区重大事项。
