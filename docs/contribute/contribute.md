# 贡献 Wiki

本 Wiki 由社区成员共同维护，欢迎任何人参与内容建设。

***

## 你可以做什么

- **补充缺失内容**：填写标注 ⛔ 的未完工条目
- **修正错误信息**：纠正过时或不准确的描述
- **改善排版表达**：优化文章可读性
- **新增页面**：为尚未收录的内容创建新条目

## 贡献方式

### 方式一：通过 GitHub 提交 PR（推荐）

1. 前往 [GitHub 仓库](https://github.com/RedStarMC) Fork 本项目
2. 在 `docs/` 目录下找到对应文件并进行编辑
3. 提交 Pull Request，描述你的改动内容
4. 等待管理员审核合并

### 方式二：联系管理员

如果你不熟悉 GitHub 操作，可以直接将修改内容（文字、截图）发送给管理员：

- **QQ 群**：568197092 · [加群链接](https://qm.qq.com/q/Xu2Ac6roMW)

## 写作规范

- 标题使用 `#` `##` `###` 层级，不要跳级
- 使用 `:::tip` / `:::note` / `:::caution` 突出重要信息
- 代码、命令使用行内代码或代码块包裹，如 `/spawn`
- 未完工的条目请在标题前加 `⛔`，并在文章顶部添加：

```md
:::caution

本页面内容尚未完工，急需时请联系管理员。

:::
