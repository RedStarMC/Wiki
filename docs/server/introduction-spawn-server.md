# 主城服务器介绍

这里介绍了一些玩家在主城时的建筑、命令，以及一些机制。

***

## 建筑

### 娱乐中心
娱乐中心前身为地图东北角瀑布上方的台球厅，现已独立为单独的岛屿区域。

通过主城岛屿亭子中的传送门即可进入。

内含多种单人小游戏，少数竞技和社交游戏。更多玩法开发中。
### 摸鱼神殿
摸鱼神殿内摆有代表服务器管理组成员的npc。你可以与npc右键交互以获得一些有趣的剧情。

如果你加入管理组，你的npc也会摆在里面
## 命令

和其他玩家交互：

* /tpa 玩家名 ---申请传送到该玩家
* /tpahere 玩家名 ---申请其他玩家传送到自己
* /warnings 玩家名 ---查询这个玩家在主城的被警告记录

直接使用：

* /spawn ---返回主城
* /warp ---查看地标
* /bs ---打开菜单
* /world ---切换所在世界

## 机制

* 在主城，右键楼梯或半砖可以坐下。
