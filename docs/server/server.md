# 社区服务器

import DocCardList from '@theme/DocCardList';

RedStarMC 目前运营多个子服，适合不同玩法偏好的玩家。

## 子服一览

| 子服 | 版本 | 定位 | 状态 |
|---|---|---|---|
| 登录服 | — | 注册与登录入口 | 运行中 |
| 主城服 | 1.21.x | 社交、商业、传送枢纽 | 运行中 |
| 生存二服 | 1.21 | 粘液科技 + 生存 | 半归档 |
| 生存三服 | 1.21.11 | 原版生存 + 职业经济 | 运行中 |
| 生电服 | 1.21.1 Fabric | 原版生电，白名单申请制 | 运行中 |

:::caution 生存二服说明

生存二服目前处于**半归档状态**，不再接受版本更新，但仍可正常进入游玩。

:::
:::tip 不知道选哪个子服？

- **刚加入** → 先看 [登录服信息](login-comands.md)，完成注册后进入主城
- **想玩生存 + 插件** → [生存三服](introduction-survival-three-server.md)（推荐新玩家）
- **想玩粘液科技** → [生存二服](introduction-survival-two-server.md)（注意：半归档状态）
- **想玩原版生电** → [生电服](introduction-survival-redstone-engineering-server.md)（需申请白名单）

:::

## 如何加入

1. 下载 Minecraft Java 版，推荐版本 **1.21.1** 或 **1.21.11**
2. 连接服务器地址（请在 QQ 群公告中查看最新 IP）
3. 在登录服完成注册后，通过主城的**跨服菜单**进入目标子服

详细的注册登录命令，请查看：[登录服信息](server-introduce/login-comands.md)
