# 登录服信息

登录服是一个由世界边界围起来的小区域。在这里进行登录和注册。点击中央的 “主城传送门” 即可进入主城服并前往服务器游玩。

***



## 命令

注册
```minecraft
  /reg 你的密码 确认密码
```

登录
```minecraft
  /login 你的密码
```

更改密码
```minecraft
  /changepassword <旧密码> <新密码>
``` 

## 首次登入

首次登入会向玩家展示进服须知，进入主城即代表您已阅读并同意须知内容

内容包括：

一、规则依据：所有规则以官方wiki为准，未覆盖情况由管理组裁决

二、内容警告：服务器可能包含恐怖/惊吓/频闪效果，敏感可申请关闭

三、入镜授权：进入即同意管理组在直播、截图等中使用你的角色画面

四、地图与建筑：生存服地图属于参与玩家共有；主城建筑版权归建筑师

五、争议裁决：矛盾冲突由管理组裁决，不服可凭证据申诉

六、虚拟财产声明：虚拟财产无现实价值，严禁RMT（真实货币交易）
